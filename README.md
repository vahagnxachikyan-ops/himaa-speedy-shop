HIMAA — Marketplace for Armenia

HIMAA is an early-stage marketplace frontend concept designed for the Armenian market. The project explores a modern online shopping experience with a focus on product discovery, convenient navigation, and a localized interface.

Project Overview

The goal of HIMAA is to create a marketplace where customers in Armenia can browse products across different categories through a simple and accessible shopping experience.

The current repository contains the frontend prototype. It is a work in progress and is not yet a production-ready e-commerce platform.

Features

* Product category navigation
* Shopping cart interface
* Responsive user interface
* Multi-language interface structure
* Login and registration interface
* Checkout interface concept

Technology Stack

* React 18
* TypeScript
* Vite
* React Router
* Tailwind CSS
* shadcn/ui
* TanStack Query
* Framer Motion
* Vitest

Getting Started

Requirements

* Node.js
* npm

Installation

Clone the repository:

git clone https://github.com/vahagnxachikyan-ops/himaa-speedy-shop.git

Navigate to the project directory:

cd himaa-speedy-shop

Install dependencies:

npm install

Start the development server:

npm run dev

Create a production build:

npm run build

Current Development Status

HIMAA is under active development.

The current version focuses on frontend structure and user experience.

Some functionality is still in prototype form:

* Product data is not yet connected to a production backend.
* Cart data is currently managed on the client side.
* Authentication is not connected to a production authentication service.
* Checkout and payment processing are not yet integrated.

These features are planned areas for future development.

Project Vision

HIMAA aims to explore the potential of a locally focused marketplace for Armenia, combining accessible shopping, localized user experience, and convenient delivery-oriented commerce.
